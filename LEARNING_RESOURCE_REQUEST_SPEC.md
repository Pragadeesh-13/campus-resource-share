# Feature Specification: Post Learning Resource Request

## User Story
As a student, I want to post a request for learning resources on a specific academic topic so that peers can recommend suitable resources.

## Functional Requirements
1. **Topic Input:** Student specifies subject code, topic name, and resource type required (e.g., lecture slides, past exams, reference books).
2. **Peer Recommendations:** Allows other students/staff to reply with links, attachments, and recommended titles.
3. **Notifications:** Alerts the requester when new peer recommendations are submitted.
